# SISTEMAKLTETIQUETAS
# 🏷️ SISTEMA KLT - GERENCIAMENTO DE ETIQUETAS E COTAÇÕES DE FRETE

## 📋 Sobre o Projeto

Sistema web completo para gerenciamento de cotações de frete e geração de etiquetas de envio. Desenvolvido para atender empresas de logística e transportadoras, oferecendo uma interface intuitiva e funcionalidades robustas.

**Versão:** 2026.2.0  
**Desenvolvido por:** KLT INFORMÁTICA E TECNOLOGIA

---

## 🚀 Funcionalidades

### 1. 💰 Cotação de Frete
- Cálculo automático de frete baseado em peso, volume e distância
- Percentuais configuráveis de seguro e Ad Valorem
- Múltiplas transportadoras com valores personalizados
- Geração de relatório completo em formato texto
- Impressão e salvamento da cotação

### 2. 🏷️ Geração de Etiquetas
- Criação de etiquetas individuais por volume
- Pré-visualização antes da impressão
- Suporte para múltiplas empresas cadastradas
- Impressão direta ou salvamento em arquivo

### 3. 📊 Histórico de Cotações
- Listagem completa de todas as cotações geradas
- Visualização detalhada de cada cotação
- Armazenamento local no navegador (localStorage)

### 4. 📈 Relatórios Gerenciais
- Relatório de cotações por período
- Transportadoras mais utilizadas
- Volumes transportados por destino
- Análise de valores (menor, maior e média de fretes)

### 5. ⚙️ Configurações
- Parâmetros ajustáveis (taxas, valores por KG/volume)
- Gerenciamento de transportadoras
- Persistência das configurações
